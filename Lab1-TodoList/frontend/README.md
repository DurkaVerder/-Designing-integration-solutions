# TodoList frontend

Простое статическое приложение для `TodoList API`. Оно поддерживает:

- регистрацию и вход через JWT;
- просмотр, создание, редактирование и удаление задач;
- статус и приоритет задачи через API v2.

## Запуск

1. Запустите API из родительской папки:

   ```text
   go run ./cmd/app
   ```

2. В отдельном терминале из этой папки запустите статический сервер на порту `8081`:

   ```text
   python -m http.server 8081
   ```

3. Откройте <http://localhost:8081>.

Адрес API задаётся в начале файла `app.js` и по умолчанию равен
`http://localhost:8080/api/v2`. Порт `8081` нужен потому, что API разрешает этот
origin в CORS.
